# UI Design System & Tokens

## 1. Color Palette

### Dark Background Hierarchy

- `dark-950`: `#050811` (Root Canvas / Viewport)
- `dark-900`: `#0b1120` (Surface Background / App Frame)
- `dark-850`: `#0f172a` (Card Background / Raised Surface)
- `dark-800`: `#1e293b` (Subtle Borders / Dividers)
- `dark-700`: `#334155` (Elevated Interactive Borders)

### Spider-Man Crimson Accents

- `spider-600`: `#dc2626`
- `spider-500`: `#e53935` (Primary Interactive Brand)
- `spider-400`: `#f87171` (Hover States / Focus Rings)

### Telemetry & Radar Accents

- `radar-500`: `#06b6d4` (Cyan Data Streams)
- `radar-400`: `#22d3ee` (Radar Glows)
- `alert-500`: `#f59e0b` (Caution / Warning)
- `alert-danger`: `#ef4444` (Critical Incident)
- `success-500`: `#10b981` (Online / Healthy)

---

## 2. Typography

- **Headings & Badges**: `Outfit`, sans-serif (`font-heading`)
- **Body & Controls**: `Inter`, sans-serif (`font-sans`)
- **Telemetry & Logs**: `JetBrains Mono`, monospace (`font-mono`)

---

## 3. Glassmorphism Standards

- Background: `bg-dark-900/70` with `backdrop-blur-md`
- Border: `border border-slate-800/80`
- Inner Glow: `shadow-[0_0_25px_rgba(229,57,53,0.05)]`
